# RugShield Website

This folder contains the exported static snapshot of the current RugShield project website.

- **Live website:** https://www.genspark.ai/artifact/rE6IIiOEbP3asatrnrvv2g
- **Source snapshot:** [`index.html`](index.html)

The website presents the active Studionet deployment, Full Consensus claim result, pool state, explorer-linked transactions, documentation links, and a MetaMask wallet connection flow for account identification.

RugShield contract transactions are currently executed through GenLayer Studio. The website does not claim to submit contract transactions directly.
