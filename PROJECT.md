# RugShield Project Record

## Project

**RugShield: Consensus-Backed Rug Pull Protection**

RugShield is a complete GenLayer prototype combining a deployed Intelligent Contract, audited evidence workflow, public project website, wallet-identification UX, deployment documentation, and reproducible Full Consensus transaction evidence.

## Components

- `rugshield.py` — compatibility mirror of the deployed contract source
- `contracts/rugshield.py` — canonical project contract location
- `site/index.html` — exported website source
- `docs/ARCHITECTURE.md` — architecture and lifecycle
- `docs/DEPLOYMENT.md` — active deployment and explorer transactions
- `docs/DEMO_EVIDENCE.md` — exact Full Consensus safety-path evidence
- `docs/TESTING.md` — completed test scope
- `docs/SECURITY.md` — trust boundaries and fund-safety notes
- `docs/WEBSITE.md` — website and wallet behavior
- `docs/SUBMISSION.md` — submission-ready links and copy
- `docs/REVIEW_CHECKLIST.md` — reproducible reviewer path and scope boundary
- `tests/test_release_integrity.py` — dependency-free integrity regression tests
- `scripts/verify_release.py` — one-command release verifier
- `.github/workflows/verify.yml` — CI for every push and pull request
